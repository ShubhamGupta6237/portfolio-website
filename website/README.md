# Shubham Gupta — portfolio

Interactive portfolio for the C++20 voice-AI orchestrator at Vaani AI Research and connected-vehicle work on the New Renault Duster.

## Run locally

```bash
cd website
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).

## Stack

React, TypeScript, Vite, GSAP ScrollTrigger, Lenis, Three.js / React Three Fiber, Framer Motion.

## Build

```bash
npm run build
npm run preview
```
