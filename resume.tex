        conversations over SIP telephony, WebRTC, and chat on LiveKit, streaming STT $\rightarrow$

  \item \textbf{Made live calls outage-proof:} router-based failover with PCM replay across 21 AI vendors
        (7 STT, 6 LLM, 8 TTS, incl. Deepgram, Sarvam, OpenAI, Gemini, Groq, self-hosted Gemma on vLLM,

        finishes, and generation-ID barge-in instantly kills stale tokens and audio the moment the
        caller interrupts.
  \item \textbf{Taught it when to speak:} multimodal end-of-turn detection fusing a text EOU classifier
        with the Smart-Turn audio model on ONNX Runtime / OpenVINO, plus VAD and neural noise
        suppression across 8/16/48\,kHz audio.
  \item \textbf{Zero locks, zero allocations on the audio hot path:} lock-free ring buffers, strand-safe
        timers, and Boost.Asio, proven with RapidCheck property tests under ASan, UBSan, and TSan.
  \item \textbf{Built to extend, not edit:} ABI-stable stage contract, \texttt{dlopen} plugin host, and
        CI-enforced dependency lint; call recording, persona memory, and 12 session watchers shipped
        with zero core-engine changes.
  \item \textbf{15+ in-call tools via LLM function calling:} SIP warm/cold transfer, Cal.com booking,
        WhatsApp, RAG over pgvector, custom APIs, and voicemail detection.
  \item \textbf{Smarter conversations:} token-budgeted context with rolling summarization, persona memory
        from past calls and CRM, multilingual / Indic language switching, and guardrails.
  \item \textbf{Production-grade at scale:} actor-model agent server with Redis-backed concurrency and
        pooled connections on Kubernetes (HPA, zero-downtime deploys, 300\,s graceful drain), with
        OpenTelemetry, Prometheus, and AWS / Azure secret managers.
  \item \textbf{AI-native engineering:} authored agent rules, \texttt{AGENTS.md}, Cursor skills (incl. a
        4-phase architecture audit), and a 30K-node codebase knowledge graph that let coding agents
        ship production C++ safely.
